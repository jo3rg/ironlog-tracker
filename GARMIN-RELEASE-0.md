# Garmin release 0: deploy a workout to the watch

IRON.LOG exports a workout prescription as `.FIT` and imports the original `.FIT` file of a completed Garmin strength activity. The import is manual, offline, and idempotent for the same file.

The software side is covered automatically by `npm run test:e2e` (see `README.md`): the suite exports every plan day, validates the bytes with the Garmin FIT SDK, and imports simulated completed activities through the real UI. Everything below is what the automated suite cannot cover: the watch, Garmin Connect, and the original activity file from a real device.

## 1. Build the artifacts

```sh
npm install
npm run dist:all
```

Result:

- `dist/` – the deployable PWA (`index.html`, `garmin.js`, `manifest.json`, `sw.js`, icons). Upload this folder to any static HTTPS host.
- `dist/workouts/ironlog-ua.fit` (and `la`, `ub`, `lb`) – workout prescriptions for the default plan, generated by the same code path as the app download.

`npm run fit:export -- --day UA` regenerates a single day; `--plan hyrox-demo` switches the plan. WOD-format days (EMOM, AMRAP, For Time) are skipped because the exporter only supports strength days.

`npm run fit:export -- --no-rest` writes a second variant (`ironlog-ua-norest.fit`) without the explicit rest steps. Use it if the watch skips or misplaces the rest between sets. `--verbose` prints every step (name, duration, repetitions, exercise code) so the file can be compared with what the watch shows.

## 2. Put the workout on the watch

The app offers three transfer paths: Garmin Connect via an optional third-party importer, direct Bluetooth, or USB.

### 2a. Bluetooth from the app

1. Open IRON.LOG in Chrome or Edge on the desktop, or in Chrome on Android. iOS Safari has no Web Bluetooth.
2. Put the watch into pairing mode (Settings → Bluetooth → Pairing) and keep it close to the computer.
3. In the app: **Stats → Daten → Workout an die Uhr senden (Bluetooth)**.
4. Pick the watch in the browser's device list. The app opens Garmin's multi-link channel, creates the file on the watch and streams it in chunks; the status line shows the progress.
5. On the watch: **Workouts → Strength** must show the day name and open without an error.

How it works: the app speaks Garmin's own multi-link protocol over GATT — service `6A4E2800-667B-11E3-949A-0800200C9A66`, characteristics `6A4E281x` (receive) and `6A4E282x` (send) — and uploads with `CREATE_FILE` (5005), `UPLOAD_REQUEST` (5003) and `FILE_TRANSFER_DATA` (5004). The file lands in the watch's inbox and the watch imports it, the same path the USB copy uses. Protocol reference: [exercisetracks/garmin-ble-protocol.md](https://github.com/exercisetracks/tracks/blob/main/docs/garmin-ble-protocol.md) (measured on a fenix 6X Pro Solar) and the Gadgetbridge Garmin implementation.

If the browser shows no devices, the watch is not in pairing mode or does not expose the multi-link service. Then use 2b.

### 2b. Garmin Connect mit einer Import-Erweiterung

Garmin Connect Web hat keinen nativen Import für Workout-JSON. IRON.LOG erzeugt ein JSON im inoffiziellen Garmin-Workout-Service-Format. Zum Einlesen brauchst du eine Drittanbieter-Erweiterung, zum Beispiel [Garmin Workout Importer](https://github.com/estruyf/garmin-workout-browser-extension). Diese Erweiterung arbeitet in deiner angemeldeten Connect-Seite und erhält dadurch Zugriff auf dein Garmin-Konto. Prüfe den Anbieter und die Berechtigungen, bevor du sie installierst.

1. Öffne IRON.LOG → **Stats → Daten** und wähle **Connect-Workout (.json) exportieren**.
2. Melde dich in einem Desktop-Browser bei [Garmin Connect](https://connect.garmin.com/) an und installiere/öffne die Import-Erweiterung.
3. Importiere die heruntergeladene JSON-Datei über die Erweiterung. Der Workout-Service ist undokumentiert; Garmin kann das Format jederzeit ändern.
4. Prüfe in Garmin Connect, ob Name, Übungsreihenfolge, Sätze, Wiederholungen und Pausen stimmen.
5. Öffne die Garmin-Connect-App, synchronisiere die Uhr und sende das Workout an das Gerät.

IRON.LOG lehnt Übungen ab, für die im Exporter keine Garmin-Katalogzuordnung hinterlegt ist, statt einen nicht zugeordneten Übungsschlüssel zu exportieren. Für solche Trainingstage nutze den Connect-Workout-Builder. Die JSON-Erstellung und der Import sind nicht gegen ein echtes Connect-Konto oder eine echte Uhr validiert.

### 2c. USB (Fallback)


Garmin Connect Web does not accept workout `.FIT` files: its import covers activities and courses, workouts only travel from the Connect cloud to the device (Garmin forum, [How to Send Workouts to a Garmin Device](https://support.garmin.com/en-US/?faq=Oyqt6jUjOF8L1Rnuc9Sms8)).

1. Connect the watch to the computer with the proprietary USB cable. When the watch asks for the USB mode, choose **Mass Storage / MTP**.
2. Open the new drive in the file manager. Look for the `Garmin` folder; inside it the inbox folder `NewFiles` (some models additionally show `Garmin/Workouts`). Garmin's own manual-install instructions use `Garmin/NewFiles` ([Steps to Manually Install a File](https://support.garmin.com/en-US/?faq=rzvP53Si4O3barYoXzw5L7)).
3. Copy `dist/workouts/ironlog-ua.fit` into `NewFiles`.
4. Safely eject the drive, restart the watch, and open **Workouts → Strength**. The workout must appear and open without an error.

Notes:

- macOS does not mount MTP devices natively; use a Windows or Linux machine, or the Android File Transfer app.
- If the watch only shows a `Garmin/Workouts` folder, put the file there instead.
- If the JSON exporter rejects an exercise name, build that day in Garmin Connect or use the FIT/USB workflow above.

## 3. Check the workout on the watch

1. For the FIT workflow, exercise order and names must match the plan day. `Klimmzüge (oder Latzug breit)` and `Beinstrecker` use custom FIT labels and may appear without a Garmin exercise category or animation.
2. Every exercise must show the intended set count, rep target, and rest. The exporter reduces a rep range to its lower bound (`6-8` becomes `6`) and adds no target weight unless the app history already holds one for that exercise.
3. Run one representative set: rep counting, set completion, rest timer, and the transition to the next exercise must behave as expected.
4. Stop and save the workout. It must appear in Garmin Connect as a completed activity. This file is a **workout prescription**, not a completed activity; it must never be uploaded as an activity.

## 4. Record the activity and get it back into the app

1. Sync the watch with Garmin Connect, open the saved strength activity and choose **Export Original** to download its original `.FIT` file (usually into the browser's download folder).
2. Open IRON.LOG → **Stats → Daten → Garmin-Aktivität importieren (.FIT)** and choose that file.
3. Check **Stats**: the calendar marks the day, the volume chart shows the sets, and the personal bests list the heaviest set. The importer keeps active sets with reps and weight, duration-only sets as seconds, plus session duration, calories, and heart-rate summary. Importing the same file again is skipped.

## If something fails

| Symptom | Cause | Next step |
| --- | --- | --- |
| Browser shows no device | Watch not in pairing mode, or no multi-link service | Pair the watch, retry; otherwise use the USB route |
| Transfer stops with a timeout | The watch did not answer a status | Report the watch model and firmware; the protocol is reverse-engineered and firmware differences are possible |
| Connect Web import rejects the file | Workouts cannot be uploaded as FIT to Connect | Use the app or the USB route; only activities and courses can be uploaded |
| Watch does not show the workout after the transfer | Import batch not processed yet | Restart the watch, check Workouts → Strength |
| Watch shows an unnamed exercise | No Garmin catalog entry | Expected for custom labels; rename on the watch if needed |
| Watch skips the rest between sets | Step layout of the repeat block | Test the second file: `npm run fit:export -- --no-rest` and send that one |
| Import says "keine Garmin-Krafttrainingsaktivität" | Wrong file type | Export the **original** FIT of the activity, not TCX, GPX, or a course |
| Import says "bereits importiert" | Same file imported before | Expected; delete the entry in the history to re-import |
| Activity lands on the wrong day | Local time in the file | The importer prefers the UTC start time; report the file if the date is still wrong |

## Known limits

- `garmin.js` generates the `.FIT` workout locally. It does not call Garmin APIs.
- `garmin-ble.js` talks to the watch over Bluetooth with Garmin's reverse-engineered multi-link protocol. It is verified against a mock watch in the test suite, not against real hardware yet.
- The Bluetooth route needs Web Bluetooth: Chrome, Edge or Android. iOS Safari is not supported.
- The app exports the selected day from the active plan, not a completed workout from history.
- Exercise catalog mappings cover common names only. Unmapped names use Garmin's `unknown` category plus a custom exercise title; watch rendering varies by model.
- Repetition ranges are reduced to their lower bound. Weight is inferred from the latest saved set for the same exercise ID/name; confirm it is sensible before sending.
- The activity importer accepts strength activities that contain FIT set records. It imports active sets only; Garmin exercises without a workout-step/title mapping use a category-based or generic label.
- Import is manual; there is no Garmin account connection, automatic result sync, or live phone control. Watch hardware behavior remains unverified until tested on a real device.
